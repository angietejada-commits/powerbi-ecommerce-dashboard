# Ecommerce Sales and Inventory Dashboard

Dashboard desarrollado en Power BI para analizar ventas e inventario de una tienda de comercio electrónico.

## Funcionalidades
- Ventas totales por mes
- Ventas por categoría
- Ventas por producto
- Ventas por ciudad
- Indicadores KPI:
  - Revenue
  - Profit
  - Profit Margin

## Herramientas utilizadas
- Power BI
- DAX
- Modelado de datos
- Visualización de información
